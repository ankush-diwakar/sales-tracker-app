🚀 Vidyarthi Inc. - Smart Business Manager
Vidyarthi Inc. is a modern, mobile-first POS (Point of Sale) & Analytics application designed to help small businesses (stationery shops, cyber cafes, retail) track sales, calculate profits, and visualize growth in real-time.

Built with React Native (Expo) and NeonDB (PostgreSQL), it replaces traditional paper ledgers with a sleek, "Dark Mode" interface featuring powerful data visualization and cloud sync.

✨ Key Features
📊 Real-Time Dashboard: Live tracking of daily sales and net profit.

📈 Advanced Analytics: Interactive 3D Bar Charts, Donut Charts, and Glowing Area Charts to track trends over Today, Week, and Month.

🎨 Premium UI/UX: A polished "Twitter-style" dark theme with smooth Layout Animations, Lottie effects (confetti/empty states), and haptic feedback.

☁️ Cloud Database: Secure, serverless data storage using Neon (Postgres) for instant sync across devices.

👤 Smart Profile: Edit business details and profile pictures with a seamless, read/edit mode toggle.

🛠️ Tech Stack
Frontend: React Native, Expo Router, NativeWind (TailwindCSS)

Backend/DB: NeonDB (Serverless PostgreSQL), SQL

Libraries: React Native Gifted Charts, Lottie, Expo Image Picker
