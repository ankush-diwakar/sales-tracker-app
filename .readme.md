# 🚀 Vidyarthi Inc. – Smart Business Manager

**Vidyarthi Inc.** is a modern, mobile-first **POS (Point of Sale) & Business Analytics application** designed for small businesses such as stationery shops, cyber cafés, and retail stores.

The app helps business owners **track sales, calculate profits, and visualize growth in real time**, replacing traditional paper ledgers with a fast, secure, and visually rich digital solution.

Built using **React Native (Expo)** and **NeonDB (Serverless PostgreSQL)**, Vidyarthi Inc. delivers a premium **dark-mode experience** with powerful analytics, smooth animations, and cloud synchronization across devices.

---

## ✨ Key Features

### 📊 Real-Time Dashboard

- Live tracking of **daily sales**
- Instant calculation of **net profit**
- Clear overview of business performance at a glance

### 📈 Advanced Analytics

- Interactive **3D Bar Charts**
- **Donut Charts** for distribution analysis
- **Glowing Area Charts** for trend visualization
- Time-based insights: **Today / Week / Month**

### 🎨 Premium UI / UX

- Polished **Twitter-style dark theme**
- Smooth **layout animations**
- **Lottie animations** for empty states & celebrations (confetti)
- Subtle **haptic feedback** for enhanced user interaction

### ☁️ Cloud-Powered Database

- Secure, serverless data storage using **Neon (PostgreSQL)**
- Instant sync across devices
- Scalable and reliable backend infrastructure

### 👤 Smart Business Profile

- Edit business details seamlessly
- Profile picture upload support
- Smooth **read / edit mode toggle** for better usability
